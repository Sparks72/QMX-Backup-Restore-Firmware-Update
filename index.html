3 · Put the QMX into firmware update mode

Automatic, via the terminal menu: the tool opens the QMX terminal menu, reads each screen and moves the highlight by name: Main menu → System → Update firmware. It doesn't count key presses, so a remembered menu position or a reshuffled menu can't send it to the wrong item. It never presses Enter on anything containing "factory" or "reset", and it asks you before the last Enter. Click Cancel at that point for a test run: the tool backs out and leaves the terminal.

Automatic via CAT (experimental, V24): the tool looks for the "Update firmware" item in the CAT menu tree and starts it with an MM command.

Manual (always works):

  1. Click Release serial port below, because the radio drops its serial port when it reboots.
  2. On the QMX, select the Update firmware menu item. At "Sure? Click Tune", press the TUNE knob (manual section 5.20).
  3. The QMX reboots and shows up on the PC as a USB flash drive. If it doesn't, switch the QMX off and on.
4 · Copy the firmware onto the QMX drive

If the QMX drive doesn't appear on the PC, switch the QMX off and on — on some radios the drive only shows up after a restart.

Click Write to QMX drive… and pick the QMX USB drive in the folder dialog. Chrome asks once for write permission.

If the browser won't write to the drive, save the file and copy it onto the QMX drive with Explorer or Finder. This is the method the QRP Labs manual describes.

5 · Afterwards

The QMX should restart with the new firmware. Click Connect again: the log shows the new firmware version. If settings were reset, use Restore from File… with your backup.
